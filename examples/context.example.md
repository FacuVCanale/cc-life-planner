# Contexto

## Recurrentes (clases / reuniones / no negociables)

Anotá `(attention: full | partial | passive)` después del título si querés que el planner pueda meter tareas concurrentes:
- **full** (default): atención total, no concurrente.
- **partial**: podés hacer admin/shallow al mismo tiempo.
- **passive**: podés hacer cualquier cosa al mismo tiempo (incluso deep work).

## Ventanas de energía

- **Mañanas (08:00–11:00)**: alta energía, ideal para deep work / código complejo / estudio.
- **Mediodía (13:00–14:00)**: comida, evitar agendar.
- **Tarde (14:00–17:00)**: energía media. Ok para shallow work, code review, escritura.
- **Tarde-noche (17:00–20:00)**: energía baja. Admin, lectura, planning.
- **Noche (20:00+)**: descanso. Nada de trabajo si se puede evitar.

## Días cortos

- Sábados: el local cierra a las 13:00, tarde libre.
- Domingos: solo planning + revisión semanal, no trabajo deep.

## Otros

- Horas disponibles efectivas por día: ~5h (descontando clases, transición, comidas).
- Buffer mínimo entre bloques: 15min.
- Ningún bloque > 3h sin pausa.
